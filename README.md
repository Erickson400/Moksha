# Moksha
Archive of scripts and assets for MDickie's Moksha game. </br>
This game is considered Abandonware, it can't be played on modern phones or MDickie's website. The flash file was found by inspecting MDickie's website's source, a flash emulator is required to play and run the .swf file (Ruffle recommended).</br>
The .swf file was decompiled with [jpexs-decompiler](https://github.com/jindrapetrik/jpexs-decompiler). </br>
A .cab file was also found, not sure what it's for but I'll also include it here.
